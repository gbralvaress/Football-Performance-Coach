FPC PRO V5 — ATHLETE EDITION
=============================

Versão focada exclusivamente no atleta, com visual de departamento de performance de clube.

NOVO:
- Dashboard profissional / Daily Performance Status
- Readiness e recomendação automática
- Check-in diário
- Carga 7D em AU
- Trainer Mode com cronômetro
- Sessão adaptativa por posição/readiness
- Agenda de 14 dias
- Jogos e eventos
- Evolução de carga em gráfico
- Perfil técnico 0–100
- Testes físicos
- Badges/conquistas
- Perfil com posição, pé, número e objetivo
- Conta individual
- Exportação/importação JSON
- Layout responsivo para iPhone
- Cada atleta possui espaço de dados separado no navegador
